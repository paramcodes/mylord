# Features

## Auth
- Sign-in / sign-up via Clerk; protected routes; user sync to Convex.

## Servers
- Server list rail; create server modal; member list panel.

## Channels
- Channel list per server; create channel modal.

## Messaging
- Paginated message list; composer (Enter to send, Shift+Enter newline); optimistic send; realtime subscription; edit/delete with permissions.

## Presence & typing (planned)
- Online/idle/offline indicators; typing indicators; unread counts + mention badges.

## Polish (planned)
- Motion transitions; toasts (sonner); skeletons + empty states.

## Responsive
- Mobile drawer collapse for sidebars.
